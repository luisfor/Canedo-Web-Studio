# Política de seguridad

Reporta posibles vulnerabilidades de forma privada a **contacto@canedostudio.com**. El propietario autorizó publicar esta dirección para este fin. No se envió ningún correo ni se verificó la entrega o supervisión del buzón durante esta preparación.

Incluye versión del kit, descripción del impacto, pasos mínimos de reproducción y datos ficticios. No envíes credenciales activas, datos de clientes, bases completas, rutas personales ni logs sin anonimizar. Si hace falta transmitir información sensible adicional, acuerda primero un medio adecuado con el responsable.

No publiques detalles explotables, secretos ni datos privados en Issues, pull requests o comentarios públicos. Coordina la divulgación con el responsable antes de difundir detalles técnicos sensibles.

No se prometen tiempos de respuesta, corrección, soporte, recompensas o cobertura de versiones que no se hayan comprometido. No se ha comprobado ni se afirma que GitHub Private Vulnerability Reporting esté habilitado. El correo es el canal privado documentado.

Las conexiones externas son optativas; el MCP predeterminado no expone generación ni ejecución arbitraria. KIT-FIRST no controla escrituras ajenas a sus interfaces. Consulta [límites técnicos](docs/security/README.md) y [validación](docs/validation.md). No hay certificación externa de seguridad o de clientes de IA.
