# Capacidades públicas y estados

11 skills y 24 perfiles de instrucciones/detección, 80 herramientas catalogadas. Consulta `npm run kit:catalog` y `npm run kit:tools -- list` para obtener los registros reales. No se incluyen las tres skills de marketing de marca ni plugins del entorno anterior.

El diagnóstico está disponible solo para entradas marcadas; la planificación consulta dependencias/versiones/perfiles existentes. Los preparadores de runtime Node/Python/Go/Java/.NET/Rust generan configuración, no instalan sus SDKs. El reconocimiento de móvil, escritorio, Unity/IoT y otros dominios no certifica un generador o compilador.

Generadores conservados: composiciones propias Node/SQLite, business y Python/inventario. Son ejemplos de prueba opcionales; el planificador universal funciona sin capacidades comerciales. Los adaptadores de canales no certifican conexiones reales. MCP y clientes tienen [estados separados](integrations/clients.md). [Validación de esta copia](validation.md).
