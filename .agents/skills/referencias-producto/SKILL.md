# Referencias de producto
Clone Wars es un índice, no un generador ni un servidor MCP. Abre su [README original](https://github.com/GorvGoyl/Clone-Wars) cuando se necesite un candidato; no asumas que sus demos siguen funcionando.
## Selección
Identifica la función buscada, plataforma, stack y si se requiere una demo o una base mantenible. Consulta solo candidatos relevantes y sus repositorios originales. Compara:
- Comportamiento realmente implementado frente a pantallas simuladas.
- Licencia del candidato y de sus assets, dependencias, actividad y pasos reproducibles.
- Autenticación, persistencia, pruebas y dependencias externas.
- Compatibilidad con el producto del usuario y esfuerzo de adaptación.
Las estrellas no prueban seguridad ni calidad. Una entrada en el índice no concede licencia sobre el proyecto enlazado. Si no hay licencia clara, ofrece una implementación propia del comportamiento.
## Relación con REA
Cuando hay código fuente completo, usa búsqueda y herramientas normales del repositorio. Usa REA solo si la pregunta depende de un paquete distribuido, un binario o comportamiento en ejecución no establecido por ese código; conserva observaciones, inferencias y límites.
No descargues ni ejecutes todos los clones. Revisa el manifiesto y scripts de un candidato antes de ejecutar sus instaladores.
## Entrega
Registra URL, commit o fecha consultada, licencia declarada y partes revisadas. Entrega una comparación breve y después implementa la opción elegida dentro del alcance solicitado. Mantén marcas, datos y credenciales del producto original fuera del proyecto nuevo.
Para un workspace tipo Notion/AppFlowy, consulta la skill workspace-colaborativo cuando esté disponible; para arquitectura, arquitecto-fullstack. Si no están instaladas, continúa con el diseño concreto y documenta las decisiones.
